# SAUTI — Cinematic Website

Site statique prêt pour GitHub Pages.

## Mise en ligne
1. Envoyer tout le contenu de ce dossier à la racine du dépôt GitHub.
2. GitHub → Settings → Pages.
3. Source : Deploy from a branch → `main` → `/ (root)`.

## Rendez-vous visio
Le bouton final utilise actuellement `contact@agencysauti.com`. Pour utiliser Calendly/Cal.com, remplacer le `href` du bouton `PRENDRE RENDEZ-VOUS EN VISIO` dans `index.html`.

## Médias
Les vidéos sont locales dans `assets/videos/`. Le site suspend automatiquement les vidéos hors écran pour réduire la charge.
